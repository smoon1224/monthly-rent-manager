# 🏢 스마트 월세 수납 관리 시스템 (Monthly Rent Manager)

건물, 원룸, 오피스텔 등의 호실별 세입자 정보와 15개월 이상의 월별 월세 수납 현황을 직관적인 스프레드시트 형태로 기록·관리할 수 있는 순수 정적 웹 애플리케이션입니다.

외부 서버나 데이터베이스 설치 없이 브라우저 단독으로 실행되며, **GitHub Pages**를 통해 누구나 무료로 웹 호스팅하여 스마트폰이나 PC에서 언제 어디서나 접속할 수 있습니다.

---

## ✨ 주요 기능

1. **호실 및 계약 관리**:
   - 번호, 호수, 세입자 성함, 월세, 입금 약정일, 연락처, 보증금, 계약기간, 룸 타입(원룸/투룸/미투 등), 특이사항/수리 비고 기록.
   - 호실 신규 등록, 정보 수정, 삭제 기능 지원.

2. **직관적인 월별 수납 장부 & 표시 개월 수 선택**:
   - 가로 스크롤 시에도 **[호수, 세입자] 열이 좌측에 고정(Sticky Column)**되어 편리함.
   - **📅 입금 달 수 선택 기능**: 상단 바에서 **최근 3달, 6달, 12달, 전체, 또는 1~12달/직접 입력**을 선택하여 원하는 기간만 맞춤 표시 (기본: 최근 3달).
   - 선택한 표시 기간(`YYYY-MM ~ YYYY-MM`) 및 연도/월 헤더 구분(`25년 06월`) 제공.
   - 셀 원클릭으로 **납부 완료 일자 입력(예: `06/10`), 오늘 날짜 빠른 완료, 미납(X) 처리, 입력 취소**.
   - 하단 열별로 `수납액 / 청구예정액` (예: `315 / 315만`) 및 전체 총보증금, 총월세 자동 집계.

3. **정보 보이기 / 숨기기 (보안 모드)**:
   - 원클릭으로 세입자 이름(`홍*동`), 연락처(`010-****-1234`), 보증금(`****`)을 마스킹하여 주변 시선으로부터 개인정보 보호.

4. **강력한 데이터 백업 & 복원 (Data Backup & Restore)**:
   - **💾 데이터 백업 (JSON)**: 전체 호실 및 납부 기록을 날짜가 포함된 JSON 파일(`월세관리_백업_YYYY-MM-DD.json`)로 즉시 컴퓨터에 다운로드 보관.
   - **📂 복원 (불러오기)**: 보관해 둔 백업 파일을 업로드하면 새 기기나 다른 브라우저에서도 1초 만에 그대로 복원.
   - **📊 엑셀 (CSV) 내보내기**: 엑셀에서 바로 열어보고 인쇄할 수 있도록 UTF-8 BOM 한글 호환 CSV 다운로드 지원.
   - **로컬 자동 저장**: 브라우저의 `LocalStorage`에 모든 데이터가 실시간 안전 보관되므로 새로고침하거나 창을 닫아도 데이터 유지.

## 🚀 GitHub에 올려서 무료 서비스하는 방법 (GitHub Pages 배포)

이 프로젝트는 빌드 과정(Node.js 등)이 필요 없는 순수 정적 파일(`index.html`, `style.css`, `app.js`, `sample-data.js`)로 구성되어 있어, GitHub에 올리기만 하면 1분 안에 무료로 웹페이지가 개설됩니다.

### 📌 방법 1: GitHub 웹사이트에서 클릭 몇 번으로 올리기 (가장 쉬운 방법)

1. [GitHub](https://github.com/)에 로그인 후 우측 상단의 **[+]** 아이콘 클릭 ➜ **[New repository]** 선택.
2. 저장소 이름(Repository name)에 원하는 이름 입력 (예: `monthly-rent` 또는 `rent-manager`).
3. 공개 범위(Public)를 **Public**으로 선택하고 아래의 **[Create repository]** 초록색 버튼 클릭.
4. 첫 화면의 안내 문구 중 **"uploading an existing file"** 파란색 링크 클릭.
5. 이 폴더의 다음 파일들을 마우스로 끌어다 놓기(Drag & Drop):
   - `index.html`
   - `style.css`
   - `app.js`
   - `sample-data.js`
   - `README.md`
6. 하단의 초록색 **[Commit changes]** 버튼 클릭.
7. 저장소 상단 메뉴의 **[Settings]** ➜ 좌측 사이드바의 **[Pages]** 메뉴 클릭.
8. **Build and deployment** 항목의 **Branch**를 `None`에서 **`main`** (또는 `master`)으로 변경하고 우측의 **[Save]** 클릭.
9. 약 1~2분 후 페이지 상단에 생성된 주소 확인:
   - 👉 `https://<내-깃허브-아이디>.github.io/<저장소이름>/`
   - 이제 이 주소를 스마트폰 홈 화면에 바로가기로 추가하거나 브라우저 북마크에 넣어두고 언제든 월세를 관리하실 수 있습니다!

---

### 📌 방법 2: Git 명령어로 올리기 (개발자용)

```bash
cd monthly-rent-manager
git init
git add .
git commit -m "feat: 월세 관리 웹앱 최초 커밋"
git branch -M main
git remote add origin https://github.com/<내-아이디>/<저장소이름>.git
git push -u origin main
```
이후 GitHub 저장소의 **Settings ➜ Pages**에서 `main` 브랜치를 활성화하시면 됩니다.

## 💡 사용 팁

- **다른 기기(스마트폰 ↔ PC)로 데이터를 옮길 때**:
  1. 기존 기기에서 **[💾 데이터 백업 (JSON)]** 버튼을 눌러 파일을 저장합니다 (카카오톡 나에게 보내기나 메일로 전송).
  2. 새 기기에서 웹페이지에 접속한 뒤 **[📂 복원 (불러오기)]**를 눌러 해당 파일을 선택하면 즉시 모든 장부가 동일하게 복원됩니다.
- **초기 상태로 되돌리고 싶을 때**:
  - 상단의 **[🔄 원본 이미지 데이터 복원]** 버튼을 누르면 첨부하셨던 17개 호실 및 15개월 수납 데이터 전체로 언제든지 다시 복원됩니다.
